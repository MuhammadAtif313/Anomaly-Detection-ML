
# Anomaly Detection Using Machine Learning

## Overview
This beginner-friendly machine learning project detects unusual data points using the Isolation Forest algorithm.

## Technologies
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## How It Works
1. Generate sample numerical data.
2. Add unusual values to the dataset.
3. Train an Isolation Forest model.
4. Classify observations as normal or anomalous.
5. Visualize the results in a scatter plot.

## Installation

Create and activate a virtual environment, then install dependencies:

```bash
python -m pip install -r requirements.txt
```

## Run the Project

```bash
python main.py
```

The program displays the detected anomalies and saves the graph as `anomaly_detection.png`.

## Algorithm
Isolation Forest — an unsupervised anomaly detection algorithm.

## Dataset
The project generates synthetic numerical data, including normal observations and deliberately inserted unusual values.
